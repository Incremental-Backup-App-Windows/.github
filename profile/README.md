## 🚀 What It Is
Incremental Backup for Windows starts with one complete backup and then, on every run afterward, saves only the files that are new or changed. Because unchanged data is skipped, jobs stay fast and your backup destination stays compact. Scheduling keeps the process automatic, versioning preserves earlier copies of your files, and restore lets you bring back exactly the version you need. It is a practical, honest answer to the question of how incremental backup works in day-to-day use.

> After the first full copy, each later backup is only as big as the changes since the previous run — that is what keeps incremental backups quick and light.

## ✨ Key Features
- ⚡ **Fast incremental backups** — Only new and modified files are copied after the first full backup, so runs finish quickly.
- 🗓️ **Flexible scheduling** — Automate backups hourly, daily, or weekly so protection happens on its own.
- 🕒 **Version history** — Retain multiple versions of your files and roll back to an earlier one whenever you need it.
- 🔄 **Point-in-time restore** — Recover a single file, a folder, or a full set from the exact date you choose.
- 📦 **Space-saving storage** — Skipping unchanged files keeps your backup drive from filling up unnecessarily.

**Incremental vs differential backup — what's the difference?**
Both save changes after a full backup, but they measure change differently. An incremental backup stores only what changed since the previous backup of any kind, so each file stays small. A differential backup stores everything changed since the last full backup, so it grows steadily until you take a new full backup. Incremental favors speed and small size per run; differential favors simpler restores at the cost of larger files over time.
